# GymnaskillZ · הסוכן האישי שלך לסטודיו 💪

**רוצים להזמין שיעור בלי להיכנס לאפליקציה?** הסקיל הזה מחבר את הסוכן האישי שלכם (Claude / ChatGPT / Hermes / כל סוכן תומך) לחשבון המתאמן שלכם ב‑GymnaskillZ, ונותן לכם לשלוט בלוח השיעורים שלכם בשיחה פשוטה.

> "תרשום אותי לשיעור Strength מחר ב‑16:00"
> "מה יש לי השבוע בלוח?"
> "יש מקום פנוי בשיעור של 18:00?"
> "תבטל לי את השיעור של מחר"

---

## מה זה נותן לך

- 📅 **לוח השיעורים שלך** — כל השיעורים הקרובים עם מדריך, שעה ומספר מקומות פנויים
- ✅ **הרשמה בשיחה** — בלי לחפש באפליקציה, בלי לשכוח
- ❌ **ביטול בקלות** — כשמשהו משתנה
- 🎟️ **מצב הכרטיסייה/מנוי** — כמה נשאר ומה זמין לך
- 🩺 **הטופס הרפואי** — תזכורת אם חסר
- ⭐ **דירוג מדריכים**

הכל דרך החשבון **שלך**, בדיוק כמו באפליקציה — רק בשיחה.

---

## איך מתחילים (2 דקות)

צריך: Python 3 וחשבון מתאמן ב‑GymnaskillZ (המספר שאליו מגיע קוד ה‑SMS).

```bash
git clone https://github.com/tomguy91/gymnaskillz-app-skill.git
cd gymnaskillz-app-skill

python3 scripts/gym.py login send --phone 9725XXXXXXX   # קוד בן 4 ספרות ב‑SMS
python3 scripts/gym.py login verify 1234                # מתחברים
```

וזהו. מכאן:

```bash
python3 scripts/gym.py classes                 # השיעורים הקרובים
python3 scripts/gym.py classes --coach "<שם המאמן>"  # לפי מדריך
python3 scripts/gym.py activities              # הכרטיסייה שלך
python3 scripts/gym.py book 26633613 --yes     # הרשמה לשיעור
```

רוצים שהסוכן יעשה את זה בשבילכם? תנו לו את התיקייה הזאת ואת `SKILL.md` — והוא כבר יידע לדבר עם הסטודיו.

## שאלות נפוצות

**זה שולח סיסמה או משהו?**
לא. אין סיסמה באזור המתאמן — יש קוד חד‑פעמי ב‑SMS. הקוד והחיבור נשמרים **אצלך במחשב** בלבד (`~/.gym`, הרשאות 600), ולא נשלחים לשום מקום אחר.

**אפשר להזמין שיעור בלי כרטיסייה?**
ההרשמה כפופה לכללי הסטודיו. בלי כרטיסייה/מנוי פעיל המערכת תחזיר הודעה שצריך לפנות לסטודיו — וזה בדיוק מה שהסוכן יגיד לך.

**אני יכול לטעות ולבטל בטעות?**
הרשמה וביטול דורשים אישור מפורש (`--yes`); כברירת מחדל הסוכן רק מראה לך מה הוא עומד לעשות.

**מה עם שאר העסקים שלי בבוסטאפ?**
הסקיל נעול ל‑**GymnaskillZ** בלבד. אם יש לך חשבונות בעסקים אחרים — הוא לא ייגע בהם.
